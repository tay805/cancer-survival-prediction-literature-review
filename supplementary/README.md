# Supplementary Materials

This directory contains supporting materials associated with the cancer survival prediction literature review.

## Contents

The supplementary materials contain supporting information such as:

* Extended study-characteristics tables
* Detailed data-extraction tables
* Additional figures
* Additional analysis results
* Detailed search documentation
* Supplementary methodological information
* Additional statistical or bibliometric analyses

## Publication

Materials included with the conference or journal submission are maintained here in a form that corresponds to the relevant publication version.

## Reproducibility

The supplementary materials remain traceable to the literature database, screening records, data-extraction records, and analysis resources maintained in the repository.
