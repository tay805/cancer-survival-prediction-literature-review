# Analysis

This directory contains the computational resources used to analyse the literature-review data.

## Analysis Scope

The analysis covers quantitative and descriptive characteristics of the identified literature, including:

* Publication trends
* Cancer-type distribution
* Dataset distribution
* Data-modality distribution
* Machine learning methods
* Deep learning architectures
* Survival endpoints
* Evaluation metrics
* Validation strategies
* External validation
* Explainable artificial intelligence
* Geographic distribution
* Research themes
* Research gaps

Bibliometric and thematic analyses are included where applicable to the review methodology.

## Reproducibility

The analysis scripts use the structured literature and data-extraction datasets maintained in the `data/` directory.

Generated tables and figures are traceable to the corresponding datasets and analysis procedures.

## Software Environment

The programming languages, libraries, software packages, and relevant versions used for computational analysis are documented as part of the project.
