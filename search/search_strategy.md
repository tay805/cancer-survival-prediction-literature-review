# Search Strategy

This directory contains the search strategies and search-result records used to identify literature for the cancer survival prediction review.

## Information Sources

The literature search covers relevant scholarly databases and information sources, including:

* Scopus
* Web of Science
* PubMed
* IEEE Xplore
* ScienceDirect
* Other relevant scholarly databases where applicable

## Search Documentation

The search documentation records:

* Database name
* Search string
* Search fields
* Search date
* Publication date range
* Language restrictions, where applicable
* Filters applied
* Number of records retrieved

## Search Results

The search-result files contain the bibliographic records retrieved from the respective information sources.

Duplicate records are identified and documented during the screening and data-management process.

## Reproducibility

The exact search strings used for each database are maintained in this directory.

The search documentation provides a reproducible record of the literature-identification process and supports future updates of the review.
