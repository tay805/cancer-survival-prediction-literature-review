# Tables

This directory contains analytical and summary tables derived from the cancer survival prediction literature-review data.

## Tables

The tables present information related to:

* Characteristics of included studies
* Cancer types and subtypes
* Datasets
* Sample sizes
* Data modalities
* Machine learning methods
* Deep learning architectures
* Survival endpoints
* Evaluation metrics
* Validation strategies
* External validation
* Explainability methods
* Reported limitations
* Research gaps

## Table Management

The tables are derived from the literature database and structured data-extraction records maintained in the `data/` directory.

Analytical tables remain traceable to their underlying data and analysis procedures.

## Manuscript Tables

Tables selected for the conference or journal manuscript are formatted according to the requirements of the respective publication venue while the underlying research data remain maintained in the repository.
