# Figures

This directory contains figures generated from the analysis of the cancer survival prediction literature.

## Figures

The figures present findings from the literature review, including:

* PRISMA flow diagram
* Publication trends
* Distribution of studies by cancer type
* Distribution of datasets
* Machine learning and deep learning methods
* Survival endpoints
* Evaluation metrics
* Validation strategies
* External validation
* Explainability methods
* Research themes
* Research gaps

## Figure Management

Figures are generated from the datasets and analysis procedures maintained in the repository.

Each figure is assigned a descriptive filename and is associated with the corresponding analysis or manuscript section.

## Reproducibility

The source data and analysis resources used to generate the figures are maintained in the `data/` and `analysis/` directories.
