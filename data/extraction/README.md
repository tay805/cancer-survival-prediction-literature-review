# Data Extraction

This directory contains the structured information extracted from studies included in the cancer survival prediction literature review.

## Extraction Scope

The data-extraction records capture methodological and scientific characteristics of the included studies.

The extracted information includes:

* Study identification
* Publication details
* Cancer type and subtype
* Study population
* Dataset and data source
* Sample size
* Data modality
* Clinical features
* Genomic and molecular features
* Imaging and radiomic features
* Prediction target
* Survival endpoint
* Machine learning methods
* Deep learning architectures
* Preprocessing methods
* Feature selection methods
* Model development strategy
* Validation strategy
* External validation
* Evaluation metrics
* Explainability methods
* Reported results
* Reported limitations
* Research gaps

## Purpose

The extraction dataset provides the structured evidence base used for comparison and synthesis of the studies included in the review.

The extracted information supports the generation of analytical tables, figures, statistical summaries, and conclusions presented in the manuscript.

## Data Management

The extraction dataset is maintained under Git version control.

Changes to extracted information are recorded through the repository history.

## Reproducibility

Each extracted study is linked to its corresponding study identifier in the literature and screening datasets.

This structure maintains traceability from the original literature record through screening and eligibility assessment to the final evidence synthesis.
