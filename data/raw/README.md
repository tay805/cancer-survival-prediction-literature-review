# Raw Literature Data

This directory contains the original bibliographic records collected for the cancer survival prediction literature review.

The records represent the literature identified from the selected scholarly databases and information sources before the screening and eligibility-assessment process.

## Contents

The raw literature data contain bibliographic information such as:

* Study ID
* Authors
* Publication year
* Title
* Journal or conference
* Publication type
* DOI
* Database or information source
* Search date
* Other available bibliographic metadata

## Purpose

The raw literature dataset provides the initial evidence record from which duplicate identification, screening, eligibility assessment, and subsequent data extraction are performed.

The original records are retained to preserve the audit trail of the literature-identification process.

## Data Management

The raw literature records are maintained under Git version control.

Changes to the raw dataset are documented through the repository history.

## Copyright and Access

This directory contains bibliographic and metadata records rather than redistributed copyrighted full-text publications.
