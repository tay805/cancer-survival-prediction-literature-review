
# Cancer Survival Prediction: Literature Review

This repository contains the research materials associated with a literature review on cancer survival prediction using machine learning and deep learning.

The repository provides a structured and reproducible record of the literature identification, screening, data extraction, analysis, and manuscript development processes.

## Research Focus

The review examines the application of artificial intelligence, machine learning, and deep learning techniques for predicting cancer survival and related clinical outcomes.

The review focuses on:

* Cancer types and cancer subtypes
* Clinical and demographic variables
* Genomic and molecular features
* Imaging and radiomic features
* Multi-omics data
* Machine learning methods
* Deep learning methods
* Survival analysis approaches
* Survival prediction endpoints
* Evaluation metrics
* Validation strategies
* External validation
* Explainable artificial intelligence
* Limitations of existing approaches
* Research gaps and future directions

## Repository Structure

### `data/`

Contains the bibliographic database, screening records, and structured data extracted from the reviewed studies.

### `protocol/`

Contains the review protocol, research questions, eligibility criteria, and methodological documentation.

### `search/`

Contains the database search strategies, search strings, search dates, and search-result records.

### `analysis/`

Contains computational scripts and other resources used to analyse the literature-review data.

### `figures/`

Contains figures generated from the literature-review analysis.

### `tables/`

Contains analytical and summary tables derived from the literature-review data.

### `manuscript/`

Contains working versions of the literature-review manuscript and publication-related files.

### `supplementary/`

Contains supplementary tables, figures, methodological information, and other supporting materials.

## Reproducibility

The repository maintains a transparent and reproducible record of the literature-review process.

The literature database, screening records, data-extraction records, analysis resources, tables, figures, and manuscript materials remain linked through the repository structure and version history.

Changes to the research materials are tracked using Git and GitHub.

## Versioning

The repository uses versioned releases to preserve stable snapshots of the research materials.

Major versions correspond to meaningful stages of the literature review and its subsequent updates.

## Data Availability

Bibliographic information, screening records, extracted study characteristics, analysis resources, and other research materials that can legally and ethically be shared are maintained in this repository.

Copyrighted full-text research articles are not redistributed through this repository.

## Citation

The citation information and persistent DOI for the archived research materials are provided through Zenodo once the corresponding repository version is released.
