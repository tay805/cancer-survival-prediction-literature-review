# Review Protocol

This directory contains the methodological protocol for the cancer survival prediction literature review.

## Purpose

The protocol defines the scope, objectives, research questions, eligibility criteria, information sources, screening process, data-extraction strategy, and analysis methodology of the review.

## Contents

The protocol contains documentation related to:

* Review objectives
* Research questions
* Information sources
* Search strategy
* Inclusion criteria
* Exclusion criteria
* Screening procedure
* Data-extraction procedure
* Quality assessment
* Risk-of-bias assessment, where applicable
* Data synthesis
* Analysis methodology
* Reporting strategy

## Research Focus

The review focuses on machine learning and deep learning approaches for cancer survival prediction and related survival outcomes.

## Methodological Transparency

The protocol provides a documented methodological basis for the literature review.

Substantive changes to the review methodology are documented and reflected in the repository version history.
